Supermodel-VK 安装说明
======================================================================

一、系统要求
----------------------------------------------------------------------
  1. Windows 10 / 11（64 位）
  2. 显卡驱动建议更新到最新版
       - Vulkan 渲染器（默认）：驱动需提供 Vulkan 1.1 以上
       - OpenGL 渲染器（备选）：驱动需提供 OpenGL 4.1 以上
  3. 自备 ROM 文件（模拟器不附带任何游戏数据）

不需要安装任何运行库
----------------------------------------------------------------------
本程序是绿色版：解压后直接双击 Supermodel-VK.exe 即可运行。

  * 不需要 Visual C++ 运行库（VC++ Redistributable）
  * 不需要 DirectX、.NET、Java、Python
  * 不需要 Vulkan SDK

原因：VC++ 运行库、SDL2、SDL2_net 已全部静态编译进 exe，所以整个
文件夹里没有任何 .dll。唯一用到的 vulkan-1.dll 由显卡驱动装进系统
目录，装驱动的时候就自带，不需要单独安装。


二、第一次使用
----------------------------------------------------------------------
  1. 双击 Supermodel-VK.exe
  2. 在左边「ROM 目录」里选择存放 ROM（*.zip）的文件夹，默认 C:\Downloads
  3. 在列表里选中游戏，点「启动」或直接双击游戏名
  4. 进入游戏后：Esc 退出回界面，Alt+P 暂停，Alt+R 重置
     F5 存档，F7 读档，Alt+S 截图

首次退出时会在 Data\Config\ 生成 Supermodel.ini，之后所有设置都存在那里。


三、目录说明
----------------------------------------------------------------------
  Supermodel-VK.exe    主程序
  Data\Config\         Supermodel.ini（设置）、Games.xml（游戏列表）、Music.xml
  Data\NVRAM\          各游戏的机台存档（记录、设置）
  Data\Saves\          即时存档
  Data\Screenshots\    截图
  Data\Assets\         光枪准星贴图
  Data\Supermodel.log  运行日志（遇到问题先看这个）
  Data\README.txt      完整说明（全部按键、命令行参数等）

整个文件夹可以随意换盘符、换目录，设置和存档都跟着走，不会丢。


四、手柄：用哪种输入系统、能不能热插拔
----------------------------------------------------------------------
这一节只回答两个问题：我该在「输入系统」里选哪一项，以及插拔手柄要不要重启。

先分清界面上的两个下拉框，它们的作用完全不同：

  * 「输入系统」（Input system）—— 真正决定用哪套代码读手柄。改它才有效。
  * 「手柄型号」（Controller model）—— 只是记录一个偏好，用来在你点
    「应用」重置键位时决定采纳哪套按键布局。它本身不改输入系统。
    只有把它留在「自动检测」并按下「应用」时，检测到的建议才会被采纳。


  手柄                             输入系统          热插拔
  ----------------------------------------------------------------------
  Xbox 360 / One / Series（有线）  XInput            不支持
  PS4 / PS5（DualShock/DualSense） SDL 手柄          支持
  8BitDo（SN30 Pro+ 等，蓝牙）     SDL 手柄          支持
  老式方向盘 / 飞行摇杆 / 光枪     DirectInput 或    不支持
                                   Raw Input

  「不支持」= 开机前插好，中途插拔要重启模拟器才认。
  「支持」  = 游戏中插上立即生效，拔掉也不崩溃，插回自动恢复。

  没列到的手柄：先试「SDL 手柄」。界面底部会显示「检测到：xxx（型号，
  建议输入系统：yyy）」，照着那个建议选即可。


Xbox 手柄为什么选 XInput
----------------------------------------------------------------------
  左右扳机在 XInput 下是两个独立的轴，油门和刹车可以同时按、且都是线性
  的。SDL 手柄路径同样能分开两个扳机，但 XInput 的振动走的是微软原生通道，
  手感更接近真机。

  在 XInput 下，手柄会显示成「Xbox 360 Controller 1 (via XInput)」——
  看到这行就说明确实在用 XInput。

  换到 XInput 之后建议按一次「应用」重置键位。油门/刹车在 XInput 与
  SDL 手柄下的绑定写法相同，但如果你之前用的是 DirectInput，刹车是
  共用 Z 轴的一半，必须重绑。


8BitDo 手柄为什么必须用 SDL 手柄
----------------------------------------------------------------------
  8BitDo 的手柄有多个模式，每种模式上报的名字都不一样：
      XInput 模式  -> 「8BitDo SN30 Pro+」
      Switch 模式  -> 「Nintendo Switch Pro Controller」
      其它模式     -> 通常是「8BitDo ...」

  XInput 完全看不见蓝牙模式下的它 —— 所以这类手柄必须选「SDL 手柄」。
  选对之后界面会显示「8BitDo 手柄」。

  要知道的一点：8BitDo 的 L2/R2 是「按钮式」扳机，不是线性扳机。绑成
  刹车或油门可以用，但只有「踩死」和「松开」两档，没有中间量。这不是模拟器
  的问题，是手柄本身的硬件形态；想要线性刹车请改用 Xbox 手柄或踏板。


热插拔：哪些输入系统支持
----------------------------------------------------------------------
  支持：「SDL」和「SDL 手柄」。
      游戏运行中插上手柄会立即生效，不需要退回设置窗口重启；
      拔掉也不会崩溃，只是该手柄的按键不再响应；
      再插回去会自动恢复。
      日志（Data\Supermodel.log）里能看到对应的
      「Joystick added: ...」/「Joystick removed: ...」两行。

  不支持：XInput、DirectInput、Raw Input。
      这三套是老代码路径，只在启动时枚举一次设备。中途插拔需要退出游戏、
      回到设置窗口、重新启动游戏才认。

  所以如果你打算经常热插拔，请给支持的手柄选「SDL 手柄」；
  如果追求 XInput 的扳机与振动手感，就开机前插好，中途别拔。


按键对应关系（不看你手柄上印的字）
----------------------------------------------------------------------
  Back / Select / Share 位置 = 投币
  Start / Options / Menu  位置 = 启动 / 确认

  按键在「按键」页里逐个修改。默认布局是「标准布局（Xbox / PS 通用）」，
  Xbox 与 PS 手柄的按钮编号是通用的，区别只在印字。

五、常见问题
----------------------------------------------------------------------
Q: 游戏列表全是灰色「未收录」，一个都启动不了。
A: 先确认「ROM 目录」选对了、里面有 .zip；如果目录是对的，则是
   Data\Config\Games.xml 丢失 —— 它记录了模拟器支持哪些游戏，
   必须和 exe 一起保留。请从压缩包里完整解压后再运行。

Q: 报错 "Vulkan: volkInitialize failed. Is vulkan-1.dll installed?"
A: 显卡驱动太旧或不支持 Vulkan。先更新显卡驱动；也可以在界面「常用」页的
   「渲染器」里改选 OpenGL（New3D）后运行，不需要 Vulkan。

Q: 怎么换成别的渲染器 / 开 CRT 滤镜？
A: 「渲染器」在界面右侧的「常用」页（第一个分页），可选 Vulkan 3D / New 3D /
   Legacy 3D。
   CRT 滤镜（扫描线、荫罩点阵、辉光等）在「高级设置」页，只对 Vulkan 渲染器
   生效。
   改完点底部的「保存设置」。

Q: 提示缺少 api-ms-win-*.dll，或程序无法启动。
A: 需要 64 位 Windows 10 或更高版本。
